關鍵心法（AI 搜尋時代）

  • 步驟可觀測：每一步都要求回報「變更摘要」與「驗證方式」（例如：檔案大小／雜湊／Git diff）。
  • 邊界要清楚：交給 AI 的範圍先從「下載與上傳」開始，避免同時修改內容與部署，降低變因。
  • 人機互證：出現異常，先手動提交一次驗證平台是否正常，再回溯自動流程問題。
  • 保留快取線索：Cloudflare Pages、瀏覽器、CDN 皆可能快取；改檔名或禁快取參數可快速確認是否快取造成。

常見問題（FAQ）

Manus × GitHub × Cloudflare 基本流程是什麼？
  1. 在 GitHub 建立 Repo（含 index.html）。
  2. Cloudflare Pages 綁定該 Repo 與分支，設定建置指令（純靜態可免）。
  3. Manus 僅負責「下載／上傳」或「建立提交」，每一步都要求回報差異與驗證方式。
如何避免 AI 工具「鬼打牆」消耗積分？

設計「停損條件」與「驗證檢查點」：連續 2 次失敗就中止，改為人工提交；每步驟產出必須附「檔案大小／校驗碼／Git diff」。

部署成功但看不到最新內容怎麼辦？

清除瀏覽器／CDN 快取；或改檔名、在資源 URL 加上版本參數（如 ?v=20250928）。
