為什麼失敗？

  1. 任務邊界不清：同時要求下載/上傳/修復，AI 容易混亂
  2. 缺乏驗證：未要求回報檔案大小或 diff
  3. 快取/分支未檢查：造成錯覺
  4. 缺停損：無人工介入，積分被耗盡

排查清單

  • Cloudflare Pages 分支是否正確？
  • GitHub 上 index.html 是否最新？
  • 清快取（或 ?v=時間戳）
  • 路徑/大小寫是否正確？
  • 加一個 health.html 驗證頁
