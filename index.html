如何使用 Manus AI 串接 GitHub，將專案部署到 Cloudflare
次標：過程全記錄

這次的學習經驗與過程

我用 Gemini 做了一個點餐網頁，想嘗試 Manus 串接，把流程自動化：直接從 Gemini 下載檔案 → 上傳 GitHub → Cloudflare Pages 部署。

當時用的提示詞請幫我到這個網址下載 index.html 檔案，部署到 GitHub 上，並協助我將此專案部署到 Cloudflare Pages
專案名稱Artgo
Manus 上傳後結果網頁無法正常顯示，我指出可能是檔案問題，但它持續檢查測試，耗時近一小時仍未解決。
最後解決方式我直接到 GitHub 手動覆貼最新 index.html 並提交，Cloudflare Pages 隨即正常。
付出代價Manus 帳戶 1645 積分歸零，最後一句話也送不出去。
